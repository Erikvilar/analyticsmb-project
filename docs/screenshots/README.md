# Capturas do AnalyticsMB

Galeria usada no [README principal](../../README.md) para apresentar a aplicação desktop e suas capacidades de diagnóstico e QA.

## Demonstração de 13 de outubro de 2026

As cinco imagens JPEG foram fornecidas para demonstrar a aplicação com `com.whatsapp` selecionado. Os nomes recebidos do WhatsApp foram substituídos por nomes descritivos, em minúsculas e separados por hífens. O conteúdo visual foi preservado.

| Arquivo | Conteúdo |
| --- | --- |
| [analyticsmb-performance-heap-qualidade-cpu.jpeg](analyticsmb-performance-heap-qualidade-cpu.jpeg) | Tela de Performance com heap, App Quality e CPU; imagem de abertura do README. |
| [analyticsmb-maestro-editor-yaml-ui-inspector.jpeg](analyticsmb-maestro-editor-yaml-ui-inspector.jpeg) | Editor Maestro com YAML, `launchApp` e captura da tela inicial do dispositivo para inspeção. |
| [analyticsmb-estabilidade-logs-crashes-anrs.jpeg](analyticsmb-estabilidade-logs-crashes-anrs.jpeg) | Diagnóstico com fonte de logs, busca, período, severidades e abas de crashes e ANRs. |
| [analyticsmb-dispositivo-bateria-resiliencia.jpeg](analyticsmb-dispositivo-bateria-resiliencia.jpeg) | Temperatura, bateria, Android e condições de sobrevivência do processo em background. |
| [analyticsmb-relatorio-gravacao-performance.jpeg](analyticsmb-relatorio-gravacao-performance.jpeg) | Resumo de uma gravação, intervalo coletado e indicadores disponíveis, com ação de exportação. |

Essas capturas contêm métricas, informações técnicas do dispositivo e trechos de logs da sessão demonstrada. Não são um benchmark, uma auditoria do WhatsApp ou uma garantia de disponibilidade das métricas em todos os aparelhos. A seleção de um pacote na interface não comprova que cada linha de log exibida tenha sido emitida por esse pacote.

## Novas contribuições

Use nomes como `analyticsmb-<area>-<funcionalidade>.jpeg` ou `.png`, com uma legenda que descreva o que a captura realmente mostra. Atualize este catálogo e os links do README ao renomear arquivos.

Prefira perfil demonstrativo e dados sintéticos para novas capturas. Revise visualmente e remova credenciais, e-mails pessoais, seriais, conversas, notificações, caminhos privados e dados de clientes antes de publicar. Identificadores de aplicativos públicos usados em uma demonstração devem ser contextualizados, como nesta galeria; exemplos de código continuam usando packages sintéticos.
