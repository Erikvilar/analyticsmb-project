# Screenshots públicos

Somente capturas sanitizadas podem ser publicadas. Use identidade `Demo User`, e-mail `demo@example.com`, package `com.example.demo`, dispositivo genérico e dados sintéticos.

Nunca inclua tokens, e-mails reais, serial, packages internos, paths locais, dados corporativos, clientes ou logs privados.

A captura de login atual é segura e funciona como imagem principal. Novas páginas devem ser recapturadas com um perfil demonstrativo antes de entrarem no repositório.
